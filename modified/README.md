## How they are labelled

- The folder is under `modified/`, apart from my own mods in `mods/`.
- Each README starts with "Modified copy of <mod> by <author>", links the original and lists exactly what was changed.
- In each source file the `@author` line keeps the original author and names my change, the `@id` and `@name` differ from the original's, and the version keeps the original version with a suffix.
- The licence basis for each original is in [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md).

## Licence basis

Four of the originals state no licence in their header. The Windhawk catalogue, where all of them were published, says in its README: "Mods which don't specify a license are submitted under the MIT license." The other three state MIT themselves.

## Not included

Two more modified copies exist on my PC and are left out: one of a GPL-2.0 mod, which does not belong in an MIT-licensed repository, and one whose changes grew well beyond a small edit and would need its own write-up first.
